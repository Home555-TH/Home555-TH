# ระบบประเมินไม้สดสำหรับการผลิต
# Fresh Wood Assessment System for Production (AppSheet)

## ภาพรวม

ระบบประเมินไม้สด (Fresh Wood Assessment) เป็นแอปพลิเคชันที่สร้างด้วย AppSheet สำหรับจัดการและประเมินคุณภาพไม้สดก่อนนำเข้าสู่กระบวนการผลิต

## ไฟล์ข้อมูล (CSV Files)

| ไฟล์ | คำอธิบาย | จำนวนข้อมูล |
|-----|----------|-------------|
| `Wood_Inventory.csv` | รายการไม้สดในคลัง | 10 รายการ |
| `Wood_Assessment.csv` | บันทึกการประเมินคุณภาพไม้ | 8 รายการ |
| `Production_Batches.csv` | ชุดการผลิตและใบสั่งผลิต | 10 รายการ |
| `Assessment_Criteria.csv` | เกณฑ์การประเมินคุณภาพ | 8 เกณฑ์ |
| `Wood_Types.csv` | ประเภทและชนิดไม้ | 10 ประเภท |
| `Suppliers.csv` | รายชื่อซัพพลายเออร์ | 10 ราย |
| `Users.csv` | ผู้ใช้งานระบบ | 12 คน |

## การใช้งาน

### ขั้นตอนที่ 1: Import ข้อมูลเข้า Google Sheets
1. อัปโหลดไฟล์ CSV ทั้งหมดไปยัง Google Drive
2. แปลงเป็น Google Sheets
3. รวมเป็น Spreadsheet เดียวที่มีหลาย Sheet

### ขั้นตอนที่ 2: สร้างแอป AppSheet
1. เข้า [appsheet.com](https://www.appsheet.com)
2. สร้างแอปใหม่จาก Google Sheets
3. ทำตามคู่มือ `APPSHEET_SETUP_GUIDE.md`

## โครงสร้างข้อมูล

### Wood_Inventory (รายการไม้)
- `Wood_ID` - รหัสไม้ (Primary Key)
- `Wood_Type` - ประเภท (ท่อน/แปรรูป/แผ่น)
- `Wood_Species` - ชนิดไม้
- `Quantity_Pcs` - จำนวน (ชิ้น)
- `Total_Volume_M3` - ปริมาตรรวม (ลบ.ม.)
- `Moisture_Content_Pct` - ความชื้น (%)
- `Status` - สถานะ

### Wood_Assessment (การประเมิน)
- `Assessment_ID` - รหัสการประเมิน
- `Wood_ID` - รหัสไม้ที่ประเมิน
- `Moisture_Content_Pct` - ความชื้น
- `Density_KgM3` - ความหนาแน่น
- `Straightness_Score` - คะแนนความตรง (1-10)
- `Surface_Quality_Score` - คะแนนคุณภาพผิว (1-10)
- `Hardness_Score` - คะแนนความแข็ง (1-10)
- `Overall_Grade` - เกรดรวม (A, B+, B, C+, C)
- `Recommended_Use` - การใช้งานที่แนะนำ

### Production_Batches (การผลิต)
- `Batch_ID` - รหัสชุดผลิต
- `Wood_ID` - รหัสไม้ที่ใช้
- `Product_Name` - ชื่อผลิตภัณฑ์
- `Target_Quantity` - จำนวนเป้าหมาย
- `Completed_Quantity` - จำนวนที่ผลิตได้
- `Quality_Pass_Pct` - อัตราผ่านคุณภาพ (%)
- `Waste_Pct` - อัตราของเสีย (%)

## เกณฑ์การประเมินไม้

| เกณฑ์ | น้ำหนัก | คำอธิบาย |
|------|---------|----------|
| ความชื้น | 15% | ค่ายิ่งต่ำยิ่งดี (< 30% = Grade A) |
| ความหนาแน่น | 15% | กก./ลบ.ม. |
| ลายเส้นไม้ | 10% | คะแนน 1-10 |
| เกรดสี | 10% | ความสม่ำเสมอของสี |
| จำนวนตำหนิ | 15% | ยิ่งน้อยยิ่งดี |
| ความตรง | 10% | คะแนน 1-10 |
| คุณภาพผิว | 10% | คะแนน 1-10 |
| ความแข็ง | 15% | คะแนน 1-10 |

## ประเภทไม้ที่รองรับ

- **ยางพารา** - เฟอร์นิเจอร์ทั่วไป
- **ยูคาลิปตัส** - ก่อสร้าง, พาเลท
- **สัก** - เฟอร์นิเจอร์พรีเมี่ยม
- **มะฮอกกานี** - เฟอร์นิเจอร์หรู
- **กระถินณรงค์** - พาเลท, บรรจุภัณฑ์
- **ประดู่** - เฟอร์นิเจอร์โบราณ
- **สน** - งานตกแต่ง
- **ไม้ไผ่** - บรรจุภัณฑ์, ของตกแต่ง
- **แดง** - ก่อสร้างหนัก
- **ตะแบก** - เฟอร์นิเจอร์
