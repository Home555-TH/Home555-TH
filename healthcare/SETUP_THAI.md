# คู่มือติดตั้ง Healthcare Tracking Web App

## สำหรับดูแลคุณแม่ก่อน/หลังผ่าตัด (28/02/2568)

---

## ขั้นตอนการติดตั้ง

### ขั้นตอนที่ 1: เปิด Script Editor

1. เปิด Google Sheets ของคุณ: https://docs.google.com/spreadsheets/d/1TISVF2Ko2oopD8zGvve1zUAjEAHfrL_Cn9hPHbs-5-w/edit
2. คลิกเมนู **Extensions** (ส่วนขยาย) > **Apps Script**

### ขั้นตอนที่ 2: สร้างไฟล์ Code.gs

1. ลบ code เดิมใน `Code.gs` ทั้งหมด
2. Copy code จากไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวาง

### ขั้นตอนที่ 3: สร้างไฟล์ HTML

1. คลิก **+** ข้าง Files > เลือก **HTML**
2. ตั้งชื่อ `Index` (ไม่ต้องใส่ .html)
3. Copy code จากไฟล์ `Index.html` ไปวาง

4. สร้างไฟล์ HTML อีก 2 ไฟล์:
   - `Styles` - Copy จาก `Styles.html`
   - `Scripts` - Copy จาก `Scripts.html`

### ขั้นตอนที่ 4: Deploy Web App

1. คลิก **Deploy** > **New deployment**
2. คลิก **Select type** > เลือก **Web app**
3. ตั้งค่า:
   - Description: `Healthcare Tracking App`
   - Execute as: `Me`
   - Who has access: `Anyone` (หรือ `Anyone with Google account`)
4. คลิก **Deploy**
5. **คัดลอก URL** ที่ได้ - นี่คือลิงก์ Web App ของคุณ!

### ขั้นตอนที่ 5: Authorize (ครั้งแรก)

1. คลิกลิงก์ที่ได้
2. เมื่อขึ้น "Authorization required" คลิก **Review Permissions**
3. เลือก Google Account ของคุณ
4. คลิก **Advanced** > **Go to Healthcare Tracking (unsafe)**
5. คลิก **Allow**

### 4. ตารางนัดหมาย
- วันผ่าตัด 28/02/2568 (เพิ่มให้อัตโนมัติ)

### 7. ตู้เย็นและเครื่องปรุง
- **เครื่องปรุงที่ต้องมี** (เพิ่มให้อัตโนมัติ):
  - ซอสถั่วเหลือง (โซเดียมต่ำ)
  - น้ำมันมะกอก
  - น้ำผึ้งแท้
  - ขิงสด (ช่วยย่อย ลดคลื่นไส้)
  - กระเทียมสด (เสริมภูมิคุ้มกัน)
  - ขมิ้น (ต้านอักเสบ)
  - และอื่นๆ
- ติดตามของในตู้เย็น
- เตือนวันหมดอายุ

## รายการซื้อของประจำ (ทุก 3 วัน)

### โปรตีน
- ไข่ไก่ 10 ฟอง
- อกไก่ 500 กรัม
- ปลากะพง 400 กรัม
- เต้าหู้ไข่ 2 แพ็ค

### ผัก
- ผักกาดขาว 1 หัว
- แครอท 3 หัว
- ฟักทอง 500 กรัม
- ขึ้นฉ่าย 1 กำ
- มะเขือเทศ 4 ลูก

### ผลไม้
- กล้วยหอม 6 ลูก
- แอปเปิ้ล 4 ลูก

### นม
- โยเกิร์ตไขมันต่ำ 4 ถ้วย
- นมสดไขมันต่ำ 1 ลิตร

### แป้ง
- ข้าวหอมมะลิ 1 กก.
- มันฝรั่ง 3 หัว

## วิธีใช้งาน

1. **เปิด Web App** ผ่านลิงก์ที่ได้จากการ Deploy
2. **บันทึกข้อมูลสุขภาพ** ทุกวัน เช้า-เย็น
3. **ดูเมนูแนะนำ** และเลือกทำอาหารตามช่วง (ก่อน/หลังผ่าตัด)
4. **สร้างรายการซื้อของ** ทุก 3 วัน
5. **ตรวจสอบนัดหมาย** และเตรียมตัวล่วงหน้า
